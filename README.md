## 🚀 Featured project

### L-Bracket Stress Predictor

Ansys FEA, machine learning and design optimization of a parametric aluminium L-bracket.

* 67 Ansys Mechanical simulations planned with Latin Hypercube sampling
* Gaussian Process surrogate with uncertainty, about 1 MPa average error on unseen designs
* Optimized design 35 % lighter than the nominal shape, verified in Ansys
* Interactive web app with a rotatable 3D model and an instant safety check

**[Try the live app](https://l-bracket-stress-predictor.streamlit.app)** · **[See the code](https://github.com/engribrahim007/l-bracket-fea-ml-surrogate)**
